## 🚨 Instrução para a IA

1. **Leia primeiro** → [📜 GLOBAL_RULES.md](GLOBAL_RULES.md) — Regras universais que valem para TODOS os projetos.
2. **Identifique o projeto** → Vá para a pasta do projeto em `projects/`.
3. **Leia o mapa do projeto** → Cada projeto tem um `README.md` que encaminha para as subpastas.
4. **Aplique as skills** → A pasta `skills/` de cada projeto contém skills que DEVEM ser aplicadas sempre.
5. **Consulte os docs** → A pasta `docs/` contém toda a documentação e decisões já tomadas.
6. **Siga o estilo** → A pasta `style/` define o padrão visual obrigatório do projeto.
